# 岗位描述样例:AI Agent 开发工程师(用于关键词匹配演示)

## 职责

1. 负责公司 AI Agent 产品的架构设计与核心模块开发,包括 ReAct 循环、工具调用(Function Calling)、记忆管理
2. 基于 MCP 协议开发与维护工具服务器,连接内部业务系统
3. 设计和优化 RAG 检索链路(向量数据库、Rerank),提升问答准确率
4. 优化 Prompt 与推理成本,保障高并发场景下的服务稳定性
5. 跟踪大模型(LLM)前沿进展,推动 Agent 能力持续演进

## 要求

1. 本科及以上学历,计算机相关专业,3 年以上 Python 后端开发经验
2. 熟悉 LLM 应用开发:Prompt Engineering、RAG、Agent 框架(LangChain 等)
3. 理解 MCP 协议,有 MCP Server 开发经验者优先
4. 具备异步编程(asyncio)与高并发系统设计能力
5. 熟悉 Docker、CI/CD,有 FastAPI、Redis、PostgreSQL 使用经验
6. 有开源贡献或技术博客者优先

## 加分项

- 阅读过主流 Agent 框架源码,理解其执行循环与记忆机制
- 有多 Agent 编排、模型微调(SFT/LoRA)经验
