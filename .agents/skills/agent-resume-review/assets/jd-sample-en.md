# Sample Job Description: AI Agent Engineer (English, for keyword-matching demos)

## Responsibilities

1. Own the architecture and core modules of our AI Agent product, including the ReAct loop, function calling, and memory management
2. Build and maintain MCP servers that connect agents to internal systems
3. Design and tune RAG retrieval (vector database, reranking) to raise answer accuracy
4. Optimize prompts and inference cost while keeping the service stable under high concurrency
5. Track LLM frontier progress and push agent capabilities forward

## Requirements

1. BS+ in CS or related field; 3+ years of Python backend experience
2. Hands-on LLM application development: prompt engineering, RAG, agent frameworks (LangChain or similar)
3. Understanding of the MCP protocol; MCP server development experience is a plus
4. Solid async programming (asyncio) and high-concurrency system design
5. Experience with Docker, CI/CD, FastAPI, Redis, PostgreSQL
6. Open-source contributions or a technical blog are a plus

## Nice to have

- Has read a mainstream agent framework's source and understands its execution loop and memory model
- Multi-agent orchestration or fine-tuning experience (SFT/LoRA)
